# Шахматный тренер

Офлайн-PWA для разбора классических партий на iPhone. Первая партия — Каспаров — Топалов, Вейк-ан-Зее 1999.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite. Для проверки готовой сборки:

```bash
npm run validate:content
npm run build
npm run preview
```

## Установка на iPhone

1. Размести содержимое `dist/` на любом HTTPS-статическом хостинге или открой его через локальный HTTPS-сервер.
2. Открой приложение в Safari.
3. Нажми «Поделиться» → «На экран Домой».
4. После первого полного открытия урок, Stockfish и прогресс доступны без сети.

## Добавление партии

1. Скопируй `src/content/games/kasparov-topalov-1999.json` в новый JSON-файл.
2. Заполни поля из `src/content/types.ts`: метаданные, PGN, моменты и упражнения.
3. Укажи `ply` как число полуходов **перед** позицией задания, начиная с нуля.
4. Запусти `npm run validate:content`. Валидатор проверит PGN, FEN, SAN, варианты и границы `ply`.
5. Запусти `npm run build` и пройди все задания в браузере шириной 375 px.

Код экранов менять не требуется: список партий строится из массива `games`.

## Хранение данных

Прогресс, серия занятий и задачник ошибок хранятся только в `localStorage` устройства. Серверов, аккаунтов и внешних API нет. Ошибки повторяются через 1, 3 и 7 дней; после двух верных решений подряд позиция удаляется.

## Архитектура

- React + TypeScript + Vite;
- Chessground для доски, chess.js для правил;
- однопоточный Stockfish WASM в WebWorker с единой очередью запросов;
- vite-plugin-pwa/Workbox для офлайн-кэша;
- контент партий — JSON в `src/content/games/`.
