# Раунд 5 — упражнения не из своей партии

Раунд 4 принят по всем семи пунктам. Проверено независимо: `validate:content`, `verify:engine`,
`build` — зелёные; CI 31356415344 зелёный; живой бандл `index-DDb_kjBE.js` / `index-kZdCG-dA.css`
совпадает с локальным `dist/`; негативные тесты валидатора воспроизведены самостоятельно
(легальная транспозиция, `упражнений 3`, `ходов для поиска 4`); Стейниц идёт до 25.Rxh7+ с матом
в десять в объяснении; темы, тематические пороги движка и группировка главной на месте.

Но при чтении вывода `verify:engine` вылезло то, что валидатор увидеть не может.

## Проблема

Упражнения (`drills`) почти нигде не связаны с партией урока. На все восемь уроков есть один общий
пул из восьми позиций, который нарезан по урокам без оглядки на то, чья это партия:

| урок | упражнения | откуда позиции |
|---|---|---|
| lasker-bauer-1889 | Nxb5, Rd1, Qb8+, Rd8# | «Оперная партия» Морфи |
| steinitz-bardeleben-1895 | те же четыре, до символа | Морфи |
| winter-capablanca-1919 | те же четыре | Морфи |
| alekhine-yates-1922 | те же четыре | Морфи |
| rotlewi-rubinstein-1907 | те же четыре | Морфи |
| capablanca-tartakower-1924 | Rd8#, Rxe7+, Qxd7+, … | Морфи + Бёрн — Фишер |
| kasparov-topalov-1999 | все восемь | Морфи + Бёрн — Фишер + посторонняя позиция |
| byrne-fischer-1956 | gxf6, Rg8, Kd8, … | своя партия — единственный корректный урок |

Пять уроков подряд дают ребёнку одни и те же четыре позиции. В объяснении к первому упражнению
Ласкера прямо написано «Позиция взята из „Оперной партии“ Морфи» — то есть это осознанная заглушка,
которая доехала до продакшена.

`verify:engine` это пропускает, потому что позиции сами по себе тактически корректны, а
`validate-content.ts` проверяет только `game.drills.length >= 4`. Формально пункт «≥4 упражнений»
выполнен, содержательно — нет. Заявка «в Каспарове 8 упражнений» на деле означает «в Каспарове
лежит весь общий пул».

## Что нужно сделать

1. Для каждого из семи уроков (кроме byrne-fischer, он уже правильный) собрать собственные
   упражнения из позиций **этой же партии**: FEN должен встречаться в игровой линии урока или
   в её очевидном продолжении, а `answerSan` — быть ходом из этой партии либо форсированным
   выигрышем в этой позиции.
2. Добавить в `scripts/validate-content.ts` правило, которое ловит подмену механически:
   - FEN каждого упражнения обязан достигаться из PGN урока (проигрывать партию и собирать
     множество FEN по полуходам; допускать также позиции после `answerSan` из вариантов);
   - набор упражнений урока не должен совпадать с набором любого другого урока;
   - одна и та же FEN не должна встречаться больше чем в одном уроке.
3. Прогнать `validate:content`, `verify:engine`, `build`. Приложить негативное доказательство,
   как в ROUND4_VALIDATOR_PROOF.md: подставить в урок чужое упражнение и показать, что валидатор
   падает с внятным сообщением.
4. Обновить `Projects/Chess-Trainer.md`: провенанс упражнений (какая партия — источник каждого
   набора) сейчас не записан нигде, только PGN партий.

## Чего не делать

Не снижать порог `>= 4` и не «чинить» это добавлением ещё одного общего пула. Смысл упражнения —
доиграть то, что ребёнок только что разобрал.
